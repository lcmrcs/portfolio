# Portfólio Profissional — Versão final

Esta versão contém as partes anteriores e acrescenta:

- Foto principal de Luis Alberto no hero, com tratamento para tema claro e escuro;
- Trajetória profissional resumida;
- Cases de Accelerate, CREDZ e Vivo;
- Detalhes de case expansíveis por clique e teclado;
- E-mail, telefone e localização presentes no arquivo antigo enviado.

## Importante

O LinkedIn foi incluído após o fornecimento da URL do perfil profissional.
Antes de publicar o site, confirme com Luis Alberto se os demais contatos e os
resultados dos cases podem permanecer públicos.

## Como testar

Abra o arquivo `index.html` no navegador. Clique nos três cases para abrir e
fechar detalhes. Confira foto única no hero, links de e-mail e telefone, modo
escuro e menu no celular.

Também inclui favicon, navegação responsiva, animações discretas e respeito à
preferência do sistema por redução de movimento.
